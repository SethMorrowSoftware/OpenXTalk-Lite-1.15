KEY PRINCIPLES:
---------------

1. SEPARATION: Intel and ARM builds are completely separate
2. SAFETY: Original files backed up before any modification
3. REVERSIBLE: Easy to switch between ARM and Intel builds
4. ORGANIZED: All ARM work in one folder structure
5. DOCUMENTED: Clear instructions for each step

WORKFLOW:
---------

FOR EACH NEW LIBRARY:

1. Create "ARM [LibraryName]" folder
2. Create build script (copy from ARM Skia as template)
3. If gyp modifications needed:
   a. Copy original gyp to ARM build/gyp-modified/
   b. Modify for ARM64 (exclude x86 code, etc.)
   c. Update setup-arm-build.sh to install it
   d. Update restore-intel-build.sh to restore it
4. Run setup-arm-build.sh
5. Run library build script
6. Verify ARM64 architecture
7. Copy results to ARM [LibraryName]/lib/
