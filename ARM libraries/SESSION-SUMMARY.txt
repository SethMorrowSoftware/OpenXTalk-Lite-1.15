BUILD METHOD:
=============

NO GYP APPROACH:
- Direct xcodebuild with ARM64 flags
- Modify Xcode projects only when needed
- No Python 2 dependency
- Fast, simple, reproducible

Command:
```
xcodebuild -project <project> \
           -configuration Release \
           -arch arm64 \
           ARCHS=arm64 \
           ONLY_ACTIVE_ARCH=NO \
           MACOSX_DEPLOYMENT_TARGET=11.0
```
