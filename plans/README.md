# LiveCode Modernization Plans

This directory contains detailed implementation plans for major modernization efforts.

## Available Plans

### 1. macOS Modern UI Theme (10.14+ with Dark Mode)
- **File**: `macos-modern-ui-theme.md`
- **Status**: Planning phase
- **Target**: macOS 10.14+ (Mojave and later)
- **Scope**: Replace HITheme with modern AppKit rendering
- **Benefits**: Dark mode support, modern appearance, user accent colors
